## D-010：单颗 RGB 固件提前开发（2026-09-12）

用户明确要求现在编写自己的固件，完成后人工 review、边学边做。目标为套件 ESP32-WROOM-32D 和一颗四脚 RGB 灯，不再把 WLED 先行实测作为开发前置条件。单灯演示不需要购买 WS2812B 灯环。共阴/共阳、开发板引脚图和电阻规格待确认；输出默认禁用，GPIO 不设猜测值。先兼容 Receiver 现有 preset 请求，保留现有服务器/手机链路。固件编译与逻辑测试不替代设备验收。

2026-09-12 硬件补充：用户确认四脚共阴 RGB，并提供 KE3069 官方教程。官方项目06 清单为 220Ω 电阻三根、每色一路；灯珠图 R/阴极/G/B 的顺序需结合图示朝向核对实物。教程 GPIO0/2/15 与本固件保守白名单不一致，不自动采用，保持禁用输出直到接线方案确定。示例 PWM 反转与共阴说明矛盾，不照搬。

## D-011：KE3069 单灯接线方案（2026-09-12）

用户同意由 Agent 根据官方板图完成接线、配置和刷机指南。选择 IO25→220Ω→R、IO26→220Ω→G、IO27→220Ω→B，公共阴极→GND，USB 供电，BEACON_COMMON_ANODE=false；输出默认禁用，用户完成断电接线检查后在本地配置启用。官方主板页面描述 WROOM-32E，商家此前称 32D，记录差异；均按 classic ESP32 三路 GPIO 方案准备，实际模块标识/flash 容量到货核对，不据教程宣称实物已验收。
