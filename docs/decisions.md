# 设计决策

以下为首版完成后的有效决定，历史讨论不再作为待开发需求。

| ID | 决定 |
| --- | --- |
| D-001 | 仅监控 Herdr 内启动的终端 Agent |
| D-002 | Android/Termux 为主 Receiver；ESP32 经手机热点 HTTP 通信 |
| D-003 | done 绿色常亮，不设置独立自动熄灭计时器 |
| D-004 | 关闭完成会话后移除其状态，无剩余会话时 idle；通信异常为 unknown |
| D-005 | 开发过程由 Agent 执行，产品与设备验收由维护者决定；欢迎外部贡献 |
| D-006 | Herdr Unix socket 为唯一状态来源，不读取终端正文猜状态 |
| D-007 | 聚合顺序 blocked > working > unknown > done > idle |
| D-008 | 按键 Demo 不读取 Herdr，不持续发送心跳；与 Sender 交替运行 |
| D-009 | 早期私人设备默认地址属于本地部署历史；维护者随后授权环境变量方案：公开默认回环，答辩目标留在忽略的 .env.local，原 npm 命令自动加载 |
| D-010 | 使用自研 ESP32 单颗 RGB 固件，WLED/灯环为可选兼容路径 |
| D-011 | 共阴 RGB，IO25/26/27 分别控制 R/G/B，各串 220Ω，公共脚 GND |
| D-012 | 初期使用私有 GitHub 仓库协作；公开发布作为独立操作执行 |
| D-013 | 2026-09-13 用户确认首版整体完成；保留未测平台与故障边界 |
| D-014 | 2026-09-13 用户选择 Apache-2.0，整理公开文档；不自动修改远程可见性 |

手动前台启停是当前交付方式；不会在文档整理中安装守护进程、修改全局网络或操作真机服务。现有面包板布局保留 GPIO，不需要因布置优化重刷固件。
