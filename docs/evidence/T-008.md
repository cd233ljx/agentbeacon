# T-008 独立 Demo 模式验证

日期：2026-09-11

## 实现

- `demoEnabled` 默认关闭；关闭时 `/state` 返回 404。
- 启用后，`POST /state` 接收五态并立即进入 Demo，`DELETE /state` 退出。
- Demo 期间 `/v1/state` 仍执行校验、序列处理和存活刷新，但不改变当前 Demo 灯效。
- 退出时恢复最近且未超时的正式状态；没有正式状态或已超时则恢复 unknown。
- `/health` 返回 `demo_active`，便于演示脚本确认模式。
- `npm run demo -- --url http://<手机地址>:8787/v1/state` 提供独立按键 TUI：`1`～`5` 向手机 Receiver 发送人工选择的五态，`q` 发送 idle 后退出；它不连接 Herdr、不读取真实 Agent 状态。

## 验证

`npm test`：48 项通过、0 项失败。测试覆盖 TUI 五态按键映射、手动 v1 快照、目标地址校验和 HTTP 发送，以及 Receiver Demo 五态切换、正式状态隔离、退出恢复、非法状态和默认禁用。

`npm run check` 与 `git diff --check` 通过。另在本机启动 Termux 探针的同款 Receiver，经伪终端实际运行 TUI，验证按 `2` 后接收端输出 `STATE working sequence=1`，按 `q` 后输出 `STATE idle sequence=2`，TUI 以状态码 0 退出。当前手机健康检查超时，因此本次修正尚待手机服务重启后复验；没有连接真实 WLED。
