# T-008 独立 Demo 模式验证

日期：2026-09-11

## 实现

- `demoEnabled` 默认关闭；关闭时 `/state` 返回 404。
- 启用后，`POST /state` 接收五态并立即进入 Demo，`DELETE /state` 退出。
- Demo 期间 `/v1/state` 仍执行校验、序列处理和存活刷新，但不改变当前 Demo 灯效。
- 退出时恢复最近且未超时的正式状态；没有正式状态或已超时则恢复 unknown。
- `/health` 返回 `demo_active`，便于演示脚本确认模式。

## 验证

`npm test`：44 项通过、0 项失败。新增测试覆盖五态切换、正式状态隔离、退出恢复 done、过期后恢复 unknown、非法 Demo 状态和默认禁用。

`npm run check` 与 `git diff --check` 通过。测试使用回环 HTTP 和模拟输出，没有连接真实 WLED。
