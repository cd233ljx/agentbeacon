## 最终面包板坐标

仅适用于本次实物摆法：面包板到第 63 行，开发板 3V3=C40，A/B 两列露出；C48=IO25、C49=IO26、C50=IO27、C53=GND。移动或旋转开发板后必须按标号重新对应，不直接套用坐标。

| 元件 | 孔位 |
| --- | --- |
| RGB 红脚 | A60 |
| RGB 公共阴极 | A61 |
| RGB 绿脚 | A62 |
| RGB 蓝脚 | A63 |
| 红色 220Ω 电阻 | B48 ↔ B60 |
| 绿色 220Ω 电阻 | B49 ↔ B62 |
| 蓝色 220Ω 电阻 | B50 ↔ B63 |
| 地线 | A53 ↔ B61 |

用户确认灯脚从其观察方向为 R/公共阴极/G/B，并按上述布局反馈成功。三路仍用 IO25/26/27，无需重刷。断电整理，保留每路限流电阻，裸露引脚不能相碰。

## 运行现场

手机 Receiver：~/agentbeacon/releases/receiver-example，dryRun=false，设备 http://192.168.43.100；由用户前台 npm start。服务器由用户前台 npm run sender。后台测试进程已停止；不代为启停。按键 Demo 和 Sender 应交替运行，新实例会退休旧实例；HTTP Demo 当前未启用。

固件存于 Flash，可用标准 5V USB 供电；本轮未记录独立充电器/充电宝稳定性实测。设备重启后现有输出去重不保证主动补发，可重启 Receiver 重新同步，并确认热点 IP 未变。
